# Security Policy

TimerTomato is a local-first macOS app. It stores focus sessions and settings locally on the user's Mac.

## Supported Versions

Security fixes are considered for the current `main` branch.

## Reporting a Vulnerability

Please do not open a public issue for a suspected security or privacy vulnerability.

If GitHub private vulnerability reporting is enabled for this repository, use that channel. Otherwise, contact the maintainer privately through an available GitHub or project communication channel before disclosing details publicly.

Please include:

- A short description of the issue
- Steps to reproduce
- The affected app version or commit
- The expected impact
- Any suggested fix, if known

The maintainer will review the report and respond with next steps. If the issue is valid, the fix will be prioritized before public disclosure.
